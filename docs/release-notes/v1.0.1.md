This release of DiffusionDelay, a VST® 3 echo with a reverb inside its feedback loop, changes nothing you can hear or see. Its code is now shared with the other Hadronyche plug-ins, which makes future fixes easier.

## What's changed

- **Shared code:** DiffusionDelay now uses HadronycheCore, a library of the code the Hadronyche plug-ins have in common. It's built into the plug-in, so there's nothing extra to install.
- **Licences:** the installer now includes HadronycheCore's licence.

## Upgrading

Projects saved with version 1.0.0 open and sound as they did, and the saved format hasn't changed, so version 1.0.0 can still open projects saved with this one. Before this release, its audio, saved state and parameter text were compared with version 1.0.0's, and they match exactly.

## Installing

Download `DiffusionDelay-1.0.1-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default. You can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Requirements

- Windows 10 or later, 64-bit
- A VST 3 host. DiffusionDelay is developed for Cubase, and other hosts haven't been tried.
