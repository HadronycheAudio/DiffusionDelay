The first release of DiffusionDelay, a VST® 3 echo with a reverb inside its feedback loop.

## What's in it

- **Time and Feedback:** from 10 ms to 10 s, gliding like a tape head when you move it. At 100% feedback, the repeats never end.
- **Tempo sync:** note values from 1/32 to 4/1, including dotted and triplet values.
- **Diffusion:** adds early reflections before each repeat and a tail after it, scattered across the stereo image and scaled by the delay time. It builds up on each pass until there's only a mass of diffused sound. At 0, it's an exact clean echo.
- **Damper:** a shelf above about 4 kHz, in the feedback loop only, so the first repeat keeps all its top end.
- **Dry/wet and Volume.**

There's no latency.

## Installing

Download `DiffusionDelay-1.0.0-Setup.exe` below and run it. It installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default, and you can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Requirements

- Windows 10 or later, 64-bit
- A VST 3 host. DiffusionDelay is developed for Cubase, and other hosts haven't been tried.
